# FITLOG

Fitlog is a gym companion web app where you can browse, plan, save, and track workouts.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Sonner

## Key Features

- Browse Workouts
- Get Details Workout Information
- Add workouts to today's plan
- Save workouts for later
- Sort workouts by duration, burned calories and rating
